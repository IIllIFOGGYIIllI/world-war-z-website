Key Notices

  • This is an independent community project and is not an official DayZ, Discord, PlayStation, Nitrado, GitHub or Railway service.
  • The bot economy is virtual community data only. It has no cash value, cannot be withdrawn and is not a financial account.
  • Access to the Discord server, DayZ server, bot and dashboard is a revocable community privilege, subject to these policies, posted server rules and applicable platform rules.
  • Eligible linked members may submit an appeal through the protected dashboard. Availability, deadlines and supported case types depend on the current appeal settings; submitting an appeal does not automatically suspend a punishment.
  • Automated shop delivery changes DayZ mission configuration through the connected Nitrado service and normally requires a server restart plus manual in-game verification. It is a community convenience feature, not a guarantee by Bohemia Interactive or Nitrado.

# World War Z Bot Website — v1.22.106

Website v1.22.106 closes the remaining public dual-server parity gaps after Livonia reactivation. Public Server Rules and the standalone Survivor Shop now provide their own Chernarus/Livonia selectors and route all live data through the selected server context.

## Dual-server parity
- Rules can be viewed directly for either Chernarus or Livonia.
- The standalone shop can be opened directly and choose either live server without visiting the dashboard first.
- Shop server switching refreshes the server-isolated catalogue, account/order state, restart schedule, delivery locations and coordinate-map context.
- Existing dashboard, donations, currency conversion and PWA behaviour is preserved.

Pairs with Bot v1.18.112.

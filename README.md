# World War Z Bot Website — v1.23.0

Website v1.23.0 is a site-wide user-interface and information-architecture overhaul. It gives the public website, Command Centre, Survivor Shop, donation storefront, rules/policies and utility pages one consistent World War Z design language while preserving the existing Bot v1.18.113 backend and dual-server behaviour.

## Unified experience
- Shared dark military-survival visual system with consistent surfaces, spacing, typography, buttons, forms, dialogs and focus states.
- Consistent global navigation across public pages with active-page indication.
- Public Quick Access launcher with Ctrl/Cmd+K, searchable destinations and mobile-friendly access.
- Dashboard navigation alphabetised inside its existing permission groups; Overview remains pinned first.
- Survivor Shop defaults to Name A–Z on both standalone and dashboard member views.
- Donation packages, categories, items and payment methods render alphabetically without rewriting Admin-managed source data.
- Consistent responsive behaviour across desktop, laptop and mobile layouts.
- PWA cache revision advanced so the new design cannot remain hidden behind v1.22 assets.

## Compatibility
Pairs with Bot v1.18.113. No Railway/API route, database, Discord permission, Nitrado integration, map dataset, economy, order or donation data migration is required.

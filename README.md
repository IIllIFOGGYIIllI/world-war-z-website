# World War Z Website v1.55.0

World War Z community dashboard and installable PWA for Chernarus and Livonia.

## Current release
WWZ Map Integration Phase 1 upgrades the public map-link experience into the WWZ Interactive Map Hub with public POI browsing, direct Discord deep links and live public PvP/kill-zone overlays. Existing private pins, Group/Faction layers and Admin map information remain protected by the dashboard permission model.

The PWA advances to v1.55.0 without rotating the bounded map-cache generation.

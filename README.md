# World War Z Bot Website — v1.22.93

Website v1.22.93 keeps the protected **Administration → Server Feeds** workspace while removing the Location/map-link option from Server Feed configuration. Admins can still create, edit, delete, search and filter Discord event routes for events Bot v1.18.99 genuinely detects.

Each feed supports a destination Discord channel, active state, embed colour, minimized output, footer timestamp, optional custom note/embed copy and dynamic PlayStation Allow/Ignore lists. Multiple feeds may target the same event type.

The existing Zone Map, Online Players map and separately configured Zone Radar location behaviour are unchanged.

# World War Z Bot Website — v1.22.91

Static GitHub Pages website/dashboard and installable WWZ Server Companion for the World War Z PlayStation DayZ community.

## Current release

Website v1.22.91 adds **Discord-to-map deep links** for WWZ coordinate alerts. Links generated by Bot v1.18.95 can open the dashboard directly on the correct selected server and Chernarus/Livonia map, centre on the exact DayZ X/Z coordinates and show a temporary labelled marker for the detection.

The deep-link request is stored safely in the current browser tab while Discord sign-in completes, so an unauthenticated user can follow a radar link, sign in, and still arrive at the requested map position. The dashboard automatically prefers the matching WWZ server/map from the authenticated server list before initialising the marker.

All existing Admin Zones, Zone Map, Online Players, full zone configuration, PWA and corrected DayZ coordinate projection remain unchanged.

Pairs with Bot v1.18.95.

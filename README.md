# World War Z Bot Website — v1.22.92

Website v1.22.92 adds the protected **Administration → Server Feeds** workspace. Admins can create, edit, delete, search and filter Discord event routes for DayZ events that Bot v1.18.98 can genuinely detect.

Each feed supports a destination Discord channel, active state, embed colour, location/map links, minimized output, footer timestamp, optional custom note/embed copy and dynamic PlayStation Allow/Ignore lists. Multiple feeds may target the same event type so public and private channels can receive different routes.

The feature reuses the existing Railway ADM pipeline and keeps Discord channel IDs server-side behind opaque dashboard resource keys.

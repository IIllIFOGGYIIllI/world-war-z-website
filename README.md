# World War Z Website v1.51.0

Current cumulative website/PWA release for the World War Z DayZ console ecosystem.

This release overhauls the protected **Admin Operations Centre** paired with Bot v1.52.0. The workspace now brings selected-server live population and state, protected Nitrado controls, restart intelligence, service health, ADM watcher diagnostics, background-worker status, operational shortcuts, errors/history and the permanent Admin audit into one server-scoped screen.

Chernarus/Livonia isolation is preserved. Livonia Deathmatch Rotation behaviour is intentionally unchanged. The bounded map-cache generation remains unchanged.

# World War Z Bot Website — v1.22.85

Static GitHub Pages dashboard for the World War Z PlayStation DayZ community.

## Current release

Website v1.22.85 makes the remaining periodic dashboard refreshes visibility-aware. Live server status, Admin Command Centre and Tickets polling stop while the browser tab is hidden and refresh immediately when the user returns, eliminating background API traffic without reducing foreground refresh cadence.

Chernarus/Livonia routing, Shop, Delivery, map geometry and protected Railway API behaviour are unchanged.

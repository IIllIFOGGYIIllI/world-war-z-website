# World War Z Website v1.52.0

Current cumulative website/PWA release for the World War Z DayZ console ecosystem.

This release adds the protected **Moderation & Case Management Centre** paired with Bot v1.53.0. The workspace brings active warnings, Discord timeouts, Discord/DayZ bans, reviews, appeals, staff watchlists, private notes, priority case work and recent case history together without removing the deeper Queue, Cases, Ban Lists or Player Intelligence workspaces.

Player Intelligence also gains protected Watchlist and Discord Timeout controls. Chernarus/Livonia isolation is preserved, Livonia Deathmatch Rotation remains intentionally unchanged, and the bounded map-cache generation remains unchanged.

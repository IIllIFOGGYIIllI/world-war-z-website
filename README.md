# World War Z Website v1.53.0

Current cumulative website/PWA release for the World War Z DayZ console ecosystem.

This release repairs the Android Companion distribution pipeline and aligns public Chernarus presentation with the current **PvE world / fenced military PvP-zone** model. The signed Android wrapper advances to v1.0.1, GitHub Actions republishes permanent APK/ZIP release assets and writes exact release integrity metadata back to the website automatically. PWA install controls now provide a usable fallback even when the browser does not expose a native install prompt.

Chernarus/Livonia isolation is preserved, Livonia Deathmatch Rotation remains intentionally unchanged, and the bounded map-cache generation remains unchanged. Pairs with Bot v1.54.0.

WORLD WAR Z COMPANION - ANDROID DIRECT DISTRIBUTION
=================================================

CURRENT PUBLIC RELEASE
World War Z Companion v1.0.0
Package: com.worldwarz.companion
Minimum Android: Android 6.0 / API 23
Distribution: signed APK from the WWZ website (Google Play not required)

PLAYER DOWNLOAD PAGE
https://iillifoggyiilli.github.io/world-war-z-website/companion.html

HOW WEBSITE/PWA UPDATES WORK
Website changes do not require a new APK. The service worker detects each deployed
website revision and the existing PWA/TWA Update Now flow refreshes the live app.
CI now rejects deployable website changes when WWZ_PWA_UPDATE_REVISION in sw.js
was not changed in the same commit.

HOW NATIVE APK UPDATES WORK
1. Bump appVersion and appVersionCode in android-app/twa-manifest.json.
2. Update startUrl app_version and app_code to exactly match those values.
3. Commit/push. The Android workflow builds with the permanent signing key.
4. Download artifact wwz-companion-v<version>-android.
5. The artifact contains website-ready downloads/android files plus
   assets/data/companion-release.json. Copy those into the website repo.
6. Bump WWZ_PWA_UPDATE_REVISION in sw.js and deploy the website update.
7. Existing signed-app users will see a native update notice when the published
   version/version_code is newer than the version remembered by their app.

IMPORTANT SIGNING RULES
- Never upload the .jks or its Base64 contents to GitHub or chat.
- Keep using the current permanent signing key for every direct APK update.
- Production fingerprint:
  79:21:5A:49:A1:B9:5B:9E:A9:B4:63:BF:36:1E:43:87:6B:F6:D6:95:4F:0B:63:48:80:B1:9F:F4:3B:F7:D2:5F
- Because the keystore is PKCS12, GitHub's key password secret must match the
  keystore password.

The ZIP fallback exists because some in-app browsers download APKs but do not hand
them to Android Package Installer correctly. Players can extract the ZIP in Files /
My Files and tap the APK there.

WORLD WAR Z COMPANION - ANDROID DIRECT DISTRIBUTION
===================================================

CURRENT APP
Name: World War Z Companion
Package: com.worldwarz.companion
Stable version: 1.0.0
Version code: 10000

DISTRIBUTION MODEL
Signed APK and ZIP fallback files are published as durable GitHub Release assets:
companion-v<version>

The public WWZ website reads assets/data/companion-release.json and links players
to those release assets. The APK does not need to be committed to the GitHub Pages
repository.

AUTOMATIC RELEASE PUBLISHING
.github/workflows/build-wwz-companion-android.yml now:
1. builds the signed APK/AAB,
2. packages the APK + ZIP fallback,
3. creates or updates the matching GitHub Release,
4. uploads the APK and ZIP as permanent release assets,
5. keeps the AAB and assetlinks.json in the workflow artifact for later use.

The workflow uses the existing WWZ_ANDROID_* signing secrets and the permanent
production signing key. Never commit the JKS, Base64 key or passwords.

WEBSITE/PWA UPDATES
Website feature fixes continue to update through the live PWA/service worker without
requiring a new APK. Native package changes require a new appVersion/appVersionCode
and a new signed Android release.

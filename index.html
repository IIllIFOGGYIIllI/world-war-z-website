01
Available now

Connected Community Platform

The main bot, website and protected Railway systems are built and operating as one platform.

  • Discord and PlayStation account linking, verification, profiles and self-service account views.
  • Live DayZ status, population, bot health, uptime and protected Nitrado Start, Stop and Restart controls.
  • ADM monitoring, player activity, join/leave feeds, PvP statistics, leaderboards and intelligence tools.
  • Economy balances, daily rewards, transfers, persistent transaction history and standalone Coinflip, Dice, Slots, Roulette, Jackpot and Blackjack games.
  • Bounties, contracts, direct member/Admin command shortcuts and a searchable library covering the complete 93-command bot tree.
  • Adjustable bot presence, controlled bot speech, announcements and protected message-management tools.
  • Player search, notes, warnings, Discord and DayZ moderation, numbered cases, evidence, independent reviews and temporary-ban expiry.
  • Member appeals, protected appeal decisions, optional case-linked Discord tickets, support tickets and transcripts.
  • Permanent action auditing, managed Discord log destinations, configurable event routes and retryable webhook notifications.
  • Configuration backups, validation, history, exact comparisons, restore, loot, events, positions, weather, gameplay, temperature and message controls.
  • High-detail local Chernarus map with pan, zoom, fullscreen, reset, public POIs and accurate X/Z selection.
  • Member Survivor Shop, Owner catalogue editor, Items, Event Items, role rules, discounts, stock and purchase limits.
  • Automatic next-restart Normal Item delivery, saved locations, restart-bound Event Item rentals, receipts, cancellation, refund and cleanup workflows.
  • Responsive member, Admin and Owner dashboard areas with Discord sign-in and server-side role checks.
  • Railway-owned persistent database at /app/data/players.db, preserved through additive migrations and excluded from releases.
02
Current Release

Unified Production Chernarus Map

Website v1.22.37 and Bot v1.18.37 refine progression role synchronization so it uses the roles already created in Discord, assigns the existing progression headers/footers to members, synchronizes current Level/Prestige roles, and never creates roles during a sync.

  • Normal Items use temporary events.xml and cfgeventspawns.xml definitions for one next-restart spawn.
  • Event Item rentals retain price-per-restart, buyer-selected duration, remaining-restart tracking and the 30,000 restart cap.
  • Railway retires Normal Item delivery definitions after their spawn restart, while rental definitions remain active until their purchased restart count is complete; the legacy dpp_shop.json object spawner is unregistered.
  • Uses Nitrado as the authoritative DayZ ban-list source instead of presenting local bot cases as a live Nitrado list.
  • Uses Nitrado's live gameserver Banlist setting first so add/remove changes can apply without a restart, while retaining Player Management and authenticated ban.txt fallbacks.
  • Adds direct /banlist show, /banlist add, /banlist remove and /banlist wipe controls.
  • Adds protected /purge banlist last-login cleanup and keeps unknown last-login entries untouched.
  • Moves direct Discord message cleanup to /purge messages while retaining /mod purge.
  • Updates the searchable command library for the 93-command bot tree.
  • Standardises website headings with professional title casing and removes unnecessary heading full stops.
  • Adds clear Nitrado Live, File, Cached and Offline source badges to the Admin ban-list panel.
  • Uses one shared corrected JPG satellite and WRP production-road renderer across the main map, both shop coordinate pickers and Saved Delivery Locations.
  • Preserves accurate native DayZ X/Z selection, full-map Roads/Trails controls, fullscreen and zoom-dependent road detail.

Frequently asked questions

Know What Is Live—And What Comes Next

The dashboard displays live DayZ server information, a public interactive Chernarus map and each signed-in member's own survivor profile and economy summary. Verified Admins and the Owner can also use protected, audited Start, Stop and Restart controls.

Is the dashboard using live server data?

Yes. Server status, player count, capacity, map, platform, Railway uptime, Discord health, sanitized Nitrado state and update time are public. Signed-in members can also load their own verified profile and economy summary.

Can I sign in with Discord?

Yes. Discord identifies your account, then Railway checks your current membership and roles in the World War Z server. Only the basic identify permission is requested.

Will members and Admins see the same tools?

No. Members see personal self-service areas. Admin and Owner navigation stays completely hidden unless Railway verifies the required Discord access. Railway checks again before accepting any protected server action.

Is the Chernarus map public?

Yes. Visitors can pan, zoom, search and view approved public markers without signing in. Live players, private bases, Admin positions and unpublished events are never shown.

Does the website store bot tokens?

No. Discord bot tokens, Nitrado credentials and other secrets must never be placed in this public GitHub Pages website.

Frequently asked questions

Know What Is Live—And What Comes Next

The dashboard displays live DayZ server information, a public interactive Chernarus map and each signed-in member's own survivor profile and economy summary. Verified Admins and the Owner can also use protected, audited Start, Stop and Restart controls.

Is the dashboard using live server data?

Yes. Server status, player count, capacity, map, platform, Railway uptime, Discord health, sanitized Nitrado state and update time are public. Signed-in members can also load their own verified profile and economy summary.

Can I sign in with Discord?

Yes. Discord identifies your account, then Railway checks your current membership and roles in the World War Z server. Only the basic identify permission is requested.

Will members and Admins see the same tools?

No. Members see personal self-service areas. Admin and Owner navigation stays completely hidden unless Railway verifies the required Discord access. Railway checks again before accepting any protected server action.

Is the Chernarus map public?

Yes. Visitors can pan, zoom, search and view approved public markers without signing in. Live players, private bases, Admin positions and unpublished events are never shown.

Does the website store bot tokens?

No. Discord bot tokens, Nitrado credentials and other secrets must never be placed in this public GitHub Pages website.

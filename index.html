Development roadmap

What Is Live, What Is Deferred And What Comes Next

This roadmap reflects the current production bot, website and Railway-backed systems. Completed systems stay visible, deferred verification is not treated as a blocker, and planned expansions are kept separate from features that are already live.

01
Available now

Production Community Platform

The core World War Z bot, dashboard, Survivor Shop and protected Railway services are established and operating as one connected platform.

  • Discord ↔ PlayStation account linking, profiles, economy, gambling, PvP statistics, playtime, bounties, contracts and tickets.
  • Moderation, Discord logging, Nitrado integration, server status and protected Start, Stop and Restart controls.
  • Configuration control, loot, events, positions, validation, backups, comparisons, restores and ban-list management.
  • High-detail local Chernarus map with corrected satellite tiles, production road geometry, settlement names, private pins, shared public markers and accurate DayZ X/Z selection.
  • Member Survivor Shop and Owner catalogue management with stock, role rules, discounts, purchase limits and order history.
  • Normal Item delivery through temporary cfgEffectArea.json entries, with no purchase-triggered restart and automatic cleanup after the next independent restart.
  • Vehicle/Event Item rentals kept separate on the Central Economy event workflow with restart duration, persistence, expiry, cancellation, refund and cleanup handling.
  • XP, Levels 1–100, Prestige 0–10, Discord/DayZ XP sources, economy rewards, existing-role synchronization and protected website configuration.
  • Public/member/Admin/Owner permission separation with server-side access enforcement and Railway-owned persistent records.
02
Current release

Live Survivor Shop Catalogue Expansion

Website v1.22.46 and Bot v1.18.44 connect Shop Administration to the live DayZ Central Economy catalogue and add progressive real-item preview resolution from DayZ Wiki while keeping category artwork as a fallback.

  • Best-effort automatic catalogue sync after bot startup plus an Owner-only manual re-sync action.
  • Live types.xml classnames are categorised and assigned default prices scaled to the current World War Z economy.
  • Existing manually configured names, prices, stock, roles, discounts, limits and delivery settings are preserved.
  • Live vehicle event children remain separate restart-bound rentals and are enforced at exactly $1 per restart.
  • Catalogue capacity is expanded beyond the previous 500-item ceiling.
  • Member and dashboard shop cards now support preview images, with automatic category artwork and optional item-specific HTTPS images.
  • The existing site-wide v1.22.42 visual system, restart intelligence and closed Chernarus map stack remain intact.
03
Deferred verification

Natural XP & Prestige QA

The progression system is operational. Natural production verification can be confirmed later as real members cross the relevant milestones; it is not blocking other development.

  • Confirm a genuine level crossing updates the correct Discord role, economy reward, announcement, /rank and /profile exactly once.
  • Confirm a natural Level 100 → Prestige transition preserves Lifetime XP, resets current progression correctly and assigns the appropriate Prestige/Level roles.
  • Confirm the Prestige economy reward remains duplicate-safe during the natural transition.
  • No historical PvP XP backfill is planned.
04
Planned expansion

Livonia & Multi-Map Support

Livonia is a planned first-class map expansion rather than a reskin of the existing Chernarus page. It will receive its own validated map data and map-aware website workflows.

  • Build a Livonia satellite tile pyramid from an approved local source and establish its authoritative world dimensions, bounds and DayZ coordinate conversion.
  • Extract/reconstruct and validate Livonia roads and trails independently from the closed Chernarus production dataset.
  • Add Livonia settlement/place-name data, attribution, map validation and browser performance checks.
  • Add map selection so Chernarus and Livonia can use the same shared map UI without mixing coordinates or assets.
  • Make saved delivery locations, shop checkout, public markers and private pins map-aware.
  • Preserve the completed Chernarus map exactly unless a genuine Chernarus defect is demonstrated.
05
Planned expansion

Multi-Server Architecture

After the map model is ready for more than one world, the larger server architecture can cleanly separate settings and operations across multiple DayZ services.

  • Website server selector with separate live status, map identity and operational context.
  • Per-server Nitrado service settings, mission roots, configuration files, backups and validation history.
  • Per-server catalogue items alongside optional Global shop items.
  • Per-server rentals, delivery queues, restart accounting, player activity, PvP statistics and leaderboards.
  • Per-server Admin permissions, audit context and protected actions.
  • Safe migration of the current Chernarus server into the multi-server model without replacing Railway data.

Frequently asked questions

Know What Is Live—And What Comes Next

The dashboard displays live DayZ server information, a public interactive Chernarus map and each signed-in member's own survivor profile and economy summary. Verified Admins and the Owner can also use protected, audited Start, Stop and Restart controls.

Is the dashboard using live server data?

Yes. Server status, player count, capacity, map, platform, Railway uptime, Discord health, sanitized Nitrado state and update time are public. Signed-in members can also load their own verified profile and economy summary.

Can I sign in with Discord?

Yes. Discord identifies your account, then Railway checks your current membership and roles in the World War Z server. Only the basic identify permission is requested.

Will members and Admins see the same tools?

No. Members see personal self-service areas. Admin and Owner navigation stays completely hidden unless Railway verifies the required Discord access. Railway checks again before accepting any protected server action.

Is the Chernarus map public?

Yes. Visitors can pan, zoom, search and view approved public markers without signing in. Live players, private bases, Admin positions and unpublished events are never shown.

Does the website store bot tokens?

No. Discord bot tokens, Nitrado credentials and other secrets must never be placed in this public GitHub Pages website.

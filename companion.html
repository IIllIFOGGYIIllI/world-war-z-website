Install safely

Direct Android Installation

  1. 01
    Download the official Android app

    Use the Download Android App button above. Android may ask for permission to install an app downloaded from your browser.

  2. 02
    Open it from Downloads

    If installation does not start automatically, open your Downloads folder and tap the downloaded app file (.apk).

  3. 03
    Try the alternate download if needed

    If the direct download does not work, choose Alternate Download (ZIP), extract the folder, and open the Android installation file inside.

  4. 04
    Updating the Android app

    Future official releases can normally install over your current app. Older test versions may need to be removed first.

iPhone and iPad

Install The WWZ Home Screen App

  1. 01
    Open this site in Safari

    The Android APK is not compatible with iPhones.

  2. 02
    Tap Share, then Add to Home Screen

    Confirm Add to install the WWZ Companion icon on your Home Screen.

  3. 03
    Sign in inside the installed Companion

    If Discord sends you back to Safari, copy the private sign-in link and finish sign-in inside the Home Screen Companion.

Two update layers

How Updates Work

WEBWebsite and Home Screen app updates

New website features, fixes and maps are delivered automatically. When an update is ready, the installed Home Screen app can offer an Update Now option.

APKAndroid app updates

You only need to download a new Android installation file when the Android app itself changes. The app also checks for newer official releases.

Install safely

Direct Android Installation

  1. 01
    Download the signed APK

    Use the primary APK button above. Android may ask you to allow installs from your browser or Files app.

  2. 02
    Open it from Downloads

    If Package Installer does not launch directly from the browser, open Files/My Files → Downloads and tap the APK there.

  3. 03
    Use the ZIP fallback if needed

    Some in-app browsers mishandle APK downloads. Download the ZIP, extract it in Files, then tap the APK inside.

  4. 04
    Future signed APKs install over it

    Production releases use the same permanent signing certificate. Old debug/test builds may need to be uninstalled before the signed release can be installed.

Two update layers

How Updates Work

WEBWebsite / PWA updates

Dashboard features, fixes, maps and other live website changes are delivered through the service worker. Installed WWZ apps receive the existing Update Now prompt when a new website revision is deployed.

APKNative wrapper updates

A new APK is only required when the Android package itself changes. The app remembers its native version and checks the published stable release metadata for newer signed builds.

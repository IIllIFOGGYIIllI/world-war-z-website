# Flag image sources

Actual displayed artwork:
- DayZ Store vanilla item database large item renders:

The source class names are the vanilla DayZ item IDs (for example Flag_CDF, Flag_Rooster, Flag_LivoniaPolice and Flag_Sakhal). The WWZ code maps all 34 catalogue keys to those class IDs; it no longer invents or generates flag designs.
